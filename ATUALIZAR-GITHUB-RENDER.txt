ATUALIZAÇÃO COMPLETA — DAYZOMBI

O QUE ESTA VERSÃO FAZ
- Mantém o layout compacto aprovado.
- Ao clicar em R$ 5, R$ 10, R$ 20 ou R$ 50, abre o checkout.
- Antes do pagamento, aparece o campo “Seu Nick / nome no Discord”.
- O nome é obrigatório e fica público somente após pagamento aprovado.
- Doações aparecem como: “Nome doou R$ X,XX”.
- A compra de R$ 50 aparece como: “Nome comprou o acesso aos testes”.
- A barra da meta e a lista de apoios são carregadas do Firebase.
- O mesmo paymentId nunca soma duas vezes.
- Estorno ou contestação remove o valor e o nome da lista.

COMO ATUALIZAR O GITHUB
1. Extraia este ZIP.
2. Substitua TODOS os arquivos do repositório pelos arquivos desta pasta.
3. Não envie .env, node_modules ou a chave JSON real do Firebase.
4. Faça o commit e envie para o GitHub.

CONFIGURAÇÃO DO RENDER
Build Command: npm ci
Start Command: npm start

Mantenha estas variáveis:
- MP_ACCESS_TOKEN
- MP_PUBLIC_KEY
- MP_WEBHOOK_SECRET
- NODE_VERSION=22
- PUBLIC_URL=https://loja-dayzombi.onrender.com
- FIREBASE_DATABASE_URL=https://dayzozmbi-server-default-rtdb.firebaseio.com
- FIREBASE_SERVICE_ACCOUNT_JSON

Depois use: Save, rebuild, and deploy.
